# GitHub Profile README Design

Date: 2026-09-23
Status: Approved

## Objective

Create an English GitHub Profile README that presents mungdong as an AI Agent tooling developer with strong Go and full-stack engineering experience. The profile should feel authored, technical, and restrained rather than like a generic badge dashboard.

## Audience and positioning

The primary readers are engineers, collaborators, and hiring teams. AI Agent tooling leads the story; Go and full-stack experience establishes the engineering depth behind it.

## Voice

- English only.
- Direct, calm, and technically specific.
- Prefer concrete verbs such as `build`, `design`, `automate`, and `maintain`.
- Avoid inflated labels, percentage claims, and unsupported technology claims.

## Content structure

1. A centered hero with the name, the dual-track role, a concise value proposition, and a small badge row.
2. A current-focus section covering reusable AI Agent Skills, Go tooling, and full-stack delivery.
3. A selected-work table featuring the public `skills`, `nav-next`, and `full-stack-devkit` repositories.
4. A toolbox grouped into agent systems, backend, frontend, and platform capabilities.
5. Three engineering principles connecting AI work with conventional engineering discipline.
6. A restrained closing invitation to explore repositories and collaborate.

## Visual direction

- GitHub-native and engineering-first.
- Center only the hero; keep substantive sections left aligned.
- Use native Markdown headings, tables, lists, and separators.
- Support GitHub light and dark themes without theme-specific text colors.
- Avoid animated typing banners, visitor counters, streak widgets, trophy walls, and externally rendered statistics.
- Use only a few static Shields badges with useful alt text.
- Do not add a custom banner in the first version.

## Scope

Create `README.md` in the repository root. Keep `LICENSE` unchanged. Do not add a site, workflow, generated metrics, or external statistics service.

## Validation

1. Confirm the repository is public and named `mmungdong`.
2. Confirm `README.md` is non-empty and located at the repository root.
3. Check Markdown structure and table rendering.
4. Verify every public repository link resolves.
5. Confirm every image URL uses HTTPS and has useful alt text.
6. Confirm the page remains understandable when images are unavailable.

## Success criteria

Within a few seconds, a visitor should understand that mungdong builds AI Agent tools and also has the Go and full-stack engineering ability to ship them as dependable software.
